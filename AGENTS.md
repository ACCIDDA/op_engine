# Agent guidance

## Shared manuscript writing guidance (version 4, 23 October 2026)

Before drafting or reviewing manuscript text, Methods, supplementary material,
captions, figures or mathematical arguments, read the author-style
[index](docs/author_style/jcmacdonald/README.md),
[prose guide](docs/author_style/jcmacdonald/prose.md),
[Methods guide](docs/author_style/jcmacdonald/methods.md),
[proof guide](docs/author_style/jcmacdonald/proofs.md) and
[figure guide](docs/author_style/jcmacdonald/figures.md).
The [source record](docs/author_style/jcmacdonald/sources.json) identifies the
inspected editions, source hashes and read limits. Version 4 received
[independent guidance approval](https://github.com/yoavram-lab/pp-eigentest/issues/422#issuecomment-6367360639). Installation and manuscript
application retain separate review gates. Earlier approvals remain historical.
The durable reusable local source is
`/home/jcmacdonald/Documents/author-style/jcmacdonald/`.

Use these general standards alongside this project's existing instructions.
Preserve its scientific scope, notation, claim/proof registries, privacy/export
rules, runtime, target audience, journal format and normal review workflow.
The pp-eigentest examples and MEE adaptations are local illustrations, not
venue, protocol, terminology or branch-cleanup instructions for this project.
Preserve all existing project-specific pointers below or elsewhere in this file.

Define objects, dimensions, units, strategies and scores before use, separately
in main text and SI; explain short labels and cite adopted methods, data,
software and protocols where used in Methods. Connect actual operations to
their targets, reasons and supported interpretations. Preserve attribution,
implementation/study identity, adverse findings, scientific qualifications and
pending work while removing distracting internal revision history.

Write complete statements and logical/algebraic proofs, including hypotheses,
quantifier domains/order/dependence, equality/zero/branch cases, limits and cited
theorem applicability. Use quantifier and connective words precisely. Use
pinned Lean interfaces and correspondence/axiom audits for critical logical
forms, hypotheses and feasible limit bridges; symbolic and numerical checks
remain scoped support. No proof fragment or checked conditional component
certifies a complete fitted pipeline, stochastic application or causal history.

Draw identifiable visual operations with explicit information flow. Keep
schematic-status notes in the accompanying caption. Preserve full-precision
source values and literal approved summaries; use accessible redundant visual
encodings and inspect actual source-matched figures, full captions and
colour/grayscale layout after integration at the intended printed width.
Styling admits no new scientific estimator, runtime upgrade or endpoint.

Guidance review does not approve a manuscript. After application, independently
read the complete main text and supplement, including generated inputs,
Methods, proofs, citations and captions; obtain separate independent review,
resolve findings, run applicable checks and inspect source-matched PDFs. Use
style screens as reading aids, never quotas or automatic rewrites. Update this
snapshot only through a versioned reviewed guidance change; preserve historical
evidence and use prospective semantic/audit review for warranted bound changes.
