# Contributing

The [repository contributor guide](https://github.com/ACCIDDA/op_engine/blob/main/CONTRIBUTING.md)
covers clean setup, the numerical-core/provider boundary, focused changes,
required local checks and support. Required CPU qualification is distinct from
optional GPU availability gates and large timing runs.

Read the [backend qualification matrix](../guides/backend-qualification.md) and
[replay provenance/refresh contract](../guides/replay-provenance.md) before
changing namespace or frozen-mesh behavior. The
[hierarchical numerical evidence](../guides/hierarchical-ode.md) illustrates
independent scientific equations and derivative checks.

[Citation and archiving](citation-and-archiving.md) describes the independent
core and provider release units, existing attribution, verified release
identifiers and archival follow-up.
