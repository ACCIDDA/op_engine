# Security policy

## Supported versions

| Version | Supported |
|---|---|
| Latest `0.9.x` release | Yes |
| Earlier releases | No |
| Unreleased `main` | No production support |

## Reporting a vulnerability

Report a suspected vulnerability through
[GitHub private vulnerability reporting](https://github.com/ACCIDDA/op_engine/security/advisories/new).
Do not open a public issue for a suspected security defect.

Include the affected version or commit, component, environment, reproduction
steps, and expected impact. Do not include credentials, confidential data, or
other secrets. Maintainers will coordinate disclosure and remediation through
the private advisory.

Ordinary numerical discrepancies, modeling questions, and correctness bugs
without a security impact belong in the public issue tracker.
